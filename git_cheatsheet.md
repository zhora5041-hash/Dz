| Команда | Что делает |
|---|---|
| `git config --global user.name "Имя"` | имя автора коммитов |
| `git config --global user.email "почта"` | почта автора |

ОСНОВНОЙ ЦИКЛ  90% жизни

| Команда | Что делает |
|---|---|
| `git status` | что изменилось: untracked / modified / staged / clean |
| `git add файл` или `git add .` | поставить файлы на сцену |
| `git commit -m "сообщение"` | сделать снимок |
| `git commit -am "сообщение"` | `-a` = авто-add отслеживаемых (новые файлы НЕ подберёт!) |
| `git commit --amend -m "..."` | переписать последний коммит (до пуша!) |

СОЗДАНИЕ

| Команда | Что делает |
|---|---|
| `git init` | создать базу `.git` в текущей папке |
| `git clone <url>` | скопировать готовый репо с GitHub вместе с историей |

ОСМОТР

| Команда | Что делает |
|---|---|
| `git log` | вся история |
| `git log --oneline` | компактно: строка на снимок |
| `git show <хеш>` | отчёт о снимке |
| `git show <хеш>:файл` | файл из прошлого без путешествий |
| `git diff` | что изменилось с последнего снимка (не на сцене) |

ОТКАТЫ

| Команда | Что делает |
|---|---|
| `git restore файл` | выбросить незакоммиченные правки ⚠️ без корзины |
| `git restore --staged файл` | снять со сцены (содержимое не трогает) 🟢 |
| `git checkout <хеш>` | экскурсия к снимку; назад: `git checkout main` |

ОБЛАКО

| Команда | Что делает |
|---|---|
| `git remote add origin <url>` | привязать адрес сейфа |
| `git remote -v` | список привязанных адресов |
| `git push -u origin main` | отправить историю в облако (дальше — просто `git push`) |
| `git pull` | забрать изменения из облака |
